Arte con identidad propia

RoXThal nace como un espacio dedicado a la expresión artística, combinando dibujo, pintura, diseño y tatuaje con una mirada contemporánea y personal.

Buscamos que cada persona pueda desarrollar su creatividad, aprender nuevas técnicas y encontrar su propia manera de expresarse a través del arte.

🧰 Herramientas RoXThal

Recursos prácticos para tatuadores, artistas y alumnos.

📏 Conversor de medidas

Convierte rápidamente milímetros, centímetros y pulgadas. Útil para preparar tamaños de diseños y referencias.

1 pulgada = 25,4 mm. Usa las medidas reales del área corporal antes de preparar el stencil.

📐 Escala proporcional

Mantiene la proporción original del diseño. Introduce una medida original y la medida final deseada.

🔽 Reducción / ampliación

Calcula directamente el tamaño final aplicando un porcentaje. 100 % mantiene el tamaño; 50 % lo reduce a la mitad.

🔢 Regla de tres

Resuelve proporciones: si A corresponde a B, calcula cuánto corresponde a C.

▦ Generador de cuadrícula

Divide una referencia en filas y columnas para facilitar la transferencia proporcional del dibujo.

🖤 Escala de valores

Utiliza los valores para estudiar luces, medios tonos y sombras. Antes de tatuar, identifica las masas principales de luz y sombra.

Consejo: entrecerrar los ojos ayuda a detectar las masas principales sin distraerse con los detalles.

📚 Guía rápida para tatuaje

1. Referencia

Analiza forma, anatomía, dirección, contraste y puntos focales.

2. Composición

Comprueba que el diseño funcione en la zona corporal elegida.

3. Tamaño

Define medidas antes de preparar el stencil.

4. Lectura

El tatuaje debe mantener una lectura clara incluso a distancia.

5. Contraste

Reserva los valores más oscuros para las zonas que necesiten estructura y profundidad.

🎨 Mezclador RGB

Combina rojo, verde y azul para comprender cómo se construye un color digital.

🌈 Armonías de color

Introduce un color base y genera relaciones cromáticas útiles para ilustración y pintura.

📐 Regla de tercios

Divide mentalmente el formato en tres partes horizontales y verticales. Los cruces son zonas fuertes para colocar elementos importantes.

🌓 Análisis de valores

Una buena composición puede leerse antes de observar los detalles. Trabaja primero con masas claras, medias y oscuras.

Ejercicio: intenta reducir una referencia a solo 3 valores: luz, medio tono y sombra.

📏 Proporciones

Usa una medida conocida como referencia para comparar otras dimensiones del dibujo.

✏️ Ejercicios de entrenamiento

Ejercicio 1 — 5 minutos

Dibuja una forma simple sin levantar demasiado el lápiz.

Ejercicio 2 — Valores

Reproduce una referencia utilizando solamente tres valores.

Ejercicio 3 — Composición

Crea tres miniaturas de una misma escena y cambia el punto focal.

🧒🎨 Pinta y Crea

Espacio de dibujo libre para alumnos. Funciona en pantalla táctil, con lápiz digital o con ratón. El dibujo permanece en el dispositivo y no se sube a Supabase.

Cómo usarlo: elige un color, ajusta el tamaño y dibuja con el dedo, lápiz o ratón. Usa Deshacer/Rehacer para corregir. El borrador pinta nuevamente sobre el fondo blanco.
